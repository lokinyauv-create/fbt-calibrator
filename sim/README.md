# Simulation / Симуляція

A virtual body with three VIVE trackers (`humanoid.py`) and a runner (`run.py`) that feeds it to the
**real** calibration code: T-pose → hip step → VRChat "any pose" freeze → checks the avatar's hips against
the body. Local only, nothing here is installed. Generated by AI (Claude, Anthropic).

```bash
.venv/bin/python -I sim/run.py        # automatic VRChat calibration: heights, bodies, belt spots
```

Виртуальне тіло з трьома трекерами та запуск справжнього коду калібрування: Т-поза → стегна → «будь-яка поза» у VRChat →
перевірка, чи стегна аватара йдуть за тілом. Нічого не встановлюється.

Real hip twists are saved by the app to `~/.config/fbt-calibrator/waist-recordings/*.json` (samples, heads, result) —
they can be replayed here instead of the made-up twists.
